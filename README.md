# 댓글 갈림길

유튜브 영상의 댓글에서 자주 언급된 관심사를 추출하고, 사용자가 선택한 관심사를 바탕으로 다음에 볼 관련 영상 5개를 추천하는 Streamlit 웹 서비스입니다.

## 누가, 언제 사용하나요?

- **사용자:** 재미있게 본 영상과 관련된 콘텐츠를 더 보고 싶은 유튜브 시청자
- **사용 상황:** 영상에서 여러 주제에 관심이 생겼지만 무엇을 검색해야 할지 모를 때
- **해결 방법:** 댓글에서 실제 시청자들이 많이 언급한 관심사를 보여 주고, 사용자가 고른 방향으로 다음 영상을 추천

## 주요 기능

1. 유튜브 주소에서 영상 정보 확인
2. 공개 원댓글과 대댓글 최대 500개 수집
3. 댓글별 중복을 제외한 핵심 명사 5개 추출
4. 사용자가 관심사 하나 선택
5. 선택한 관심사와 원본 영상 주제로 관련 영상 5개 추천
6. 추천 영상의 썸네일, 제목, 채널, 조회수, 길이 및 링크 표시

## 로컬 실행

```bash
pip install -r requirements.txt
```

`.streamlit/secrets.toml` 파일을 만들고 다음 내용을 입력합니다.

```toml
YOUTUBE_API_KEY = "새로 발급한 API 키"
```

실행합니다.

```bash
streamlit run app.py
```

## Streamlit Community Cloud 배포

1. 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. Streamlit Community Cloud에서 저장소와 `app.py`를 선택합니다.
3. **App settings → Secrets**에 다음과 같이 입력합니다.

```toml
YOUTUBE_API_KEY = "새로 발급한 API 키"
```

4. 저장한 뒤 앱을 재실행합니다.

실제 API 키가 담긴 `.streamlit/secrets.toml`은 GitHub에 올리지 마세요. `.gitignore`에 이미 제외 설정이 들어 있습니다.

## 추천 방식과 한계

- 한 댓글 안에서 같은 단어가 여러 번 나와도 한 번만 계산합니다.
- 일반명사와 고유명사 중 자주 나온 단어를 댓글 관심사로 사용합니다.
- 선택한 관심사와 원본 제목의 핵심어를 조합해 한국어 관련성이 높은 영상을 검색합니다.
- 이 결과는 유튜브의 개인 맞춤 추천이 아니라 댓글 관심사에 기반한 검색 결과입니다.
- 삭제·숨김 처리된 댓글과 비공개 영상은 분석할 수 없습니다.
